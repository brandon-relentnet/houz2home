# AGENTS.md — Houz2Home

Home renovation business website. Vite SPA with TanStack Router, React 19,
TypeScript, Tailwind CSS v4, and Biome.

## Commands

```sh
npm run dev        # Start dev server (port 3000)
npm run build      # Production build (outputs to dist/)
npm run preview    # Preview production build
npm run lint       # Biome lint
npm run format     # Biome format (with --write)
npm run check      # Biome check (lint + format, with --write)
```

**No test framework is configured.** There are no test files or test scripts.

## Tech Stack

| Layer     | Tool                                          |
| --------- | --------------------------------------------- |
| Build     | Vite 7                                        |
| Routing   | TanStack Router (file-based, SPA)             |
| UI        | React 19                                      |
| Language  | TypeScript (strict mode)                      |
| Styling   | Tailwind CSS 4 + Catppuccin CSS variables     |
| Icons     | @heroicons/react (outline)                    |
| Lint/Fmt  | Biome (tabs, double quotes, organize imports) |
| Gallery   | react-photo-album (masonry)                   |

## Project Structure

```
index.html                 # SPA entry point
vite.config.ts             # Vite + TanStack Router plugin + Tailwind
tsconfig.json              # Strict TS, path alias @/* -> ./src/*
biome.json                 # Linting + formatting config
src/
  main.tsx                 # React root, mounts RouterProvider
  router.tsx               # createRouter + type registration
  routeTree.gen.ts         # Auto-generated by TanStack Router plugin (readonly)
  styles.css               # Tailwind v4 imports, @theme colors, global typography
  routes/
    __root.tsx             # Root layout (Navbar + Outlet + Footer)
    index.tsx              # Home page (/)
    about.tsx              # About page (/about)
    contact.tsx            # Contact page (/contact)
    projects.tsx           # Portfolio page (/projects)
  components/
    Footer.tsx, Logo.tsx
    navbar/                # Navbar, NavLinks, NavLinkItem, HamburgerButton, Socials
    sections/              # Page sections reused across routes
  data/
    portfolioData.ts       # Portfolio photo dimensions
```

## Code Style

### Formatting (enforced by Biome)

- **Indentation:** Tabs
- **Quotes:** Double quotes
- **Semicolons:** Yes (Biome default)
- **Import sorting:** Automatic via Biome `organizeImports`
- **Line width:** Biome default (80)

Run `npm run check` to auto-fix formatting and lint issues.

### Path Aliases

```json
{ "@/*": ["./src/*"] }
```

- Use `@/` for cross-directory imports: `import X from "@/components/sections/X"`
- Use relative imports for siblings in the same directory: `import X from "./X"`

### TypeScript

- Strict mode enabled (`strict: true` in tsconfig)
- Use `interface` for component props
- Use explicit types for data arrays and function parameters
- Use `import type` for type-only imports (enforced by `verbatimModuleSyntax`)
- No `any` — use `unknown` and narrow with type guards

### Naming Conventions

| Element            | Convention       | Example                            |
| ------------------ | ---------------- | ---------------------------------- |
| Component files    | PascalCase.tsx   | `HeroSection.tsx`, `ContactCTA.tsx` |
| Data files         | camelCase.ts     | `portfolioData.ts`                 |
| Component names    | PascalCase       | `HeroSection`, `Navbar`            |
| Interfaces         | PascalCase       | `HeroSectionProps`, `FormData`     |
| Variables / props  | camelCase        | `menuOpen`, `currentPath`          |
| Directories        | lowercase        | `navbar/`, `sections/`, `data/`    |

### Component Patterns

```tsx
// Default export with function declaration
export default function HeroSection({ title, subtitle }: HeroSectionProps) {
  // ...
}
```

- Props defined via `interface` above the component
- Use `<Link to="/path">` from `@tanstack/react-router` for navigation (not `<a href>`)
- Use `useRouterState` to get current path for active link styling
- All buttons must have explicit `type` attribute (`type="button"` or `type="submit"`)
- Static data arrays defined inline in component files with typed interfaces

### Routing (TanStack Router)

- File-based routing in `src/routes/`
- `routeTree.gen.ts` is auto-generated — never edit manually
- Routes export `Route` created via `createFileRoute("/path")({ component })`
- Root layout in `__root.tsx` uses `createRootRoute` + `<Outlet />`

### State & Error Handling

- React `useState` only — no global state libraries
- Wrap async operations in `try/catch`
- Log errors with context: `console.error("Error submitting form:", error)`
- Return user-facing messages, not raw errors
- Use `finally` to reset loading state

### Styling

- Tailwind CSS v4 utility classes — no CSS Modules
- Catppuccin color palette registered via `@theme` in `styles.css`
- Theme colors: `text-text`, `bg-base`, `bg-surface0`, `text-accent`, etc.
- Custom utility classes: `page-container`, `section-container`
- Dark mode active by default (`html.dark` class in `index.html`)

### SVG Accessibility

- Decorative SVGs must have `role="img"` and `aria-label`
- Image alt text must not contain "image", "picture", or "photo"

## Key Conventions

1. **TypeScript only** — all source files use `.ts`/`.tsx`
2. **No barrel exports** — import each component by its direct file path
3. **No test files** — testing infrastructure does not exist yet
4. **Shared sections** are reused across pages (Testimonials, ContactCTA, HeroSection)
5. **No server-side runtime** — this is a client-only SPA (no API routes)
6. **`routeTree.gen.ts` is readonly** — generated by TanStack Router plugin
7. **Biome handles all formatting** — do not add Prettier or ESLint
