# AGENTS.md — Houz2Home

Home renovation business website. Client-only Vite SPA with TanStack Router,
React 19, TypeScript, Tailwind CSS v4, Motion, and Biome.

## Commands

```sh
npm run dev        # Start dev server (port 3000)
npm run build      # Production build (outputs to dist/)
npm run preview    # Preview production build
npm run lint       # Biome lint (no auto-fix)
npm run format     # Biome format (with --write)
npm run check      # Biome check (lint + format, with --write) — run before committing
```

No test framework is configured. There are no test files or test scripts.

## Tech Stack

| Layer      | Tool                                            |
| ---------- | ----------------------------------------------- |
| Build      | Vite 7 (auto code-splitting enabled)            |
| Routing    | TanStack Router (file-based, SPA)               |
| UI         | React 19                                        |
| Language   | TypeScript (strict mode, `verbatimModuleSyntax`) |
| Styling    | Tailwind CSS v4 + custom design tokens          |
| Animation  | Motion (`motion/react`) — not framer-motion     |
| Icons      | @heroicons/react (outline)                      |
| Lint/Fmt   | Biome (tabs, double quotes, organize imports)   |
| Gallery    | react-photo-album (masonry)                     |
| Fonts      | Cormorant Garamond (display), Plus Jakarta Sans (body) |

## Project Structure

```
src/
  main.tsx              # React root — mounts RouterProvider
  router.tsx            # createRouter + type registration
  routeTree.gen.ts      # Auto-generated — NEVER edit
  styles.css            # Tailwind v4 @theme tokens, base typography
  routes/               # File-based routing (/, /about, /contact, /projects)
    __root.tsx          # Root layout: Navbar + Outlet + Footer + BackToTop
  components/
    navbar/             # Navbar, NavLinks, NavLinkItem, HamburgerButton, Socials
    sections/           # Reusable page sections (HeroSection, ContactCTA, etc.)
  data/
    portfolioData.ts    # Portfolio photo entries (typed Photo[])
```

## Code Style

### Formatting (Biome)

- **Indentation:** Tabs
- **Quotes:** Double quotes
- **Semicolons:** Yes
- **Import sorting:** Automatic via Biome `organizeImports`
- **Line width:** 80 (Biome default)
- Biome ignores `routeTree.gen.ts` and `styles.css`

### Imports

- **Path alias:** `@/*` maps to `./src/*` — use for cross-directory imports
- **Relative imports:** Only for siblings in the same directory
- **Type imports:** Use `import type` (enforced by `verbatimModuleSyntax`)
- **No barrel exports** — import each component by its direct file path

```tsx
import { motion } from "motion/react";         // Third-party
import type { ReactNode } from "react";         // Type-only
import Footer from "@/components/Footer";        // Cross-directory (alias)
import NavLinks from "./NavLinks";               // Sibling (relative)
```

### TypeScript

- Strict mode: `strict`, `noUnusedLocals`, `noUnusedParameters`
- Use `interface` for component props and data shapes
- Use explicit types for data arrays and function parameters
- No `any` — use `unknown` and narrow with type guards

### Naming

| Element           | Convention     | Example                       |
| ----------------- | -------------- | ----------------------------- |
| Component files   | PascalCase.tsx | `HeroSection.tsx`             |
| Data files        | camelCase.ts   | `portfolioData.ts`            |
| Components        | PascalCase     | `HeroSection`, `Navbar`       |
| Interfaces        | PascalCase     | `HeroSectionProps`, `Photo`   |
| Variables / props | camelCase      | `menuOpen`, `currentPath`     |
| Directories       | lowercase      | `navbar/`, `sections/`        |

### Components

- Props via `interface` defined above the component
- Default export with function declaration (not arrow functions)
- All buttons must have explicit `type` attribute (`type="button"` or `type="submit"`)
- Use `<Link to="/path">` from `@tanstack/react-router` — never `<a href>` for internal nav
- Use `useRouterState` to read current pathname for active link styling
- Static data arrays defined inline with typed interfaces

### Routing (TanStack Router)

- File-based routing in `src/routes/`
- `routeTree.gen.ts` is auto-generated by the Vite plugin — never edit
- Route files export `Route` via `createFileRoute("/path")({ component })`
- Root layout in `__root.tsx` uses `createRootRoute` + `<Outlet />`
- Router has `scrollRestoration: true` and `defaultPreload: "intent"`

### Animation (Motion)

- Import from `"motion/react"` — **not** `"framer-motion"`
- Use `motion.*` components with `initial`/`animate`/`transition` for entrance animations
- Use `whileInView` + `viewport={{ once: true }}` for scroll-triggered animations
- Use `AnimatePresence` with `mode="wait"` for component transitions
- Common easing: `[0.22, 1, 0.36, 1]` (ease-out-expo)

### State & Error Handling

- React `useState` only — no global state libraries
- Wrap async operations in `try/catch`
- Log errors with context: `console.error("Error submitting form:", error)`
- Return user-facing messages, not raw errors
- Use `finally` to reset loading state

### Styling

- Tailwind CSS v4 utility classes — no CSS Modules, no inline styles
- Custom design tokens in `styles.css` via `@theme` (not Catppuccin):
  - Backgrounds: `night`, `deep`, `dark`, `dim`, `soft`
  - Text: `cream`, `warm`, `mute`
  - Accent: `gold`, `gold-light`
  - Borders: `rule`, `rule-light`
  - Fonts: `font-display` (serif), `font-body` (sans-serif)
- Usage: `text-cream`, `bg-deep`, `border-rule`, `text-gold`, `font-display`
- Utility class `label-text` for uppercase gold label styling
- Dark theme is the only theme (no light mode, no toggle)

### Accessibility

- Decorative SVGs: `role="img"` + `aria-label`
- Image alt text: descriptive, must not contain "image", "picture", or "photo"
- Interactive buttons: always include `aria-label` when text is not visible
- Form inputs: always pair with `<label htmlFor>`

## Key Rules

1. **TypeScript only** — all source files are `.ts`/`.tsx`
2. **No server runtime** — client-only SPA, no API routes
3. **`routeTree.gen.ts` is readonly** — generated by TanStack Router plugin
4. **Biome handles all formatting** — do not add Prettier or ESLint
5. **Shared sections** are reused across pages (Testimonials, ContactCTA, HeroSection)
6. **Motion, not Framer Motion** — import from `"motion/react"`
7. **No placeholder content** — use real or contextually appropriate text
